# JP Proxy - 日本代理浏览器插件

功能强大的浏览器代理插件，支持多服务器管理、多协议、智能分流。

## 功能特性

- ✅ **多服务器管理** - 添加、编辑、删除多个代理服务器
- ✅ **多协议支持** - HTTP、HTTPS、SOCKS5
- ✅ **三种代理模式**
  - 全局模式：所有流量走代理
  - 智能模式：国内网站直连，国外走代理
  - 规则模式：使用自定义规则列表
- ✅ **规则导入** - 从URL导入规则文件
- ✅ **用户认证** - 支持用户名密码认证

## 安装步骤

1. 打开 Edge 浏览器，访问 `edge://extensions/`
2. 开启「开发人员模式」
3. 点击「加载解压缩的扩展」
4. 选择 `browser-proxy-extension` 文件夹

## 使用说明

### 服务器配置

1. 点击「服务器」标签
2. 点击「+ 添加服务器」
3. 填写服务器信息：
   - 名称：自定义名称
   - 协议：HTTP / HTTPS / SOCKS5
   - 地址：服务器IP或域名
   - 端口：代理端口
   - 用户名/密码：可选

### 代理模式

| 模式 | 说明 |
|------|------|
| 全局 | 所有流量都走代理 |
| 智能 | 内置国内域名列表，国内网站直连 |
| 规则 | 使用导入的自定义规则 |

### 规则导入

在「规则」标签页：

1. **从URL导入**：输入规则文件URL，点击导入
2. **推荐规则源**：
   - GFWList（被墙网站走代理）
   - 国内域名（国内网站直连）

## 服务器配置示例

### 使用 gost 搭建 HTTPS 代理

```bash
# 在服务器上运行
./gost -L=https://user:pass@:8443
```

### 使用 3proxy

```bash
apt install -y 3proxy
# 配置 /etc/3proxy/3proxy.cfg
```

## 注意事项

1. 浏览器插件只支持 HTTP/HTTPS/SOCKS5 协议
2. 不支持 VLESS/VMess 等自定义协议
3. 如需使用 VLESS，请使用专门的客户端（V2RayN、Clash等）
