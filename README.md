# OT512 Proxy - 浏览器代理插件

**版本**: 1.2.2  
**协议**: MIT License

一款简洁高效的浏览器代理插件，实现 **TLS 加密的 HTTPS 代理**，保护您的网络通信安全。

## ✨ 功能特性

- **TLS 加密代理**: 代理连接走 TLS 加密通道，实际代理协议（HTTP/HTTPS/SOCKS5）取决于服务器端配置
- **三种代理模式**:
  - 全局模式：所有流量走代理
  - 智能模式：基于规则分流
  - 直连模式：仅本地直连
- **规则管理**: 支持自定义规则源，自动更新 GFWList
- **用户认证**: 支持用户名/密码认证
- **连接测试**: 实时测试服务器延迟
- **自动更新**: 检测新版本并提醒

## 🔧 安装方法

1. 打开 Chrome/Edge 浏览器
2. 访问 `chrome://extensions/` (或 `edge://extensions/`)
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择本项目目录

## 📖 使用说明

### 添加代理服务器

1. 点击插件图标打开弹窗
2. 切换到「服务器」标签页
3. 点击「+ 添加服务器」
4. 填写服务器信息：
   - 名称：自定义名称
   - 地址：服务器域名（需配置 TLS 证书）
   - 用户名/密码：认证信息

> **重要提示**：
> - 本插件仅支持 TLS 加密的 HTTPS 代理（固定端口 443）
> - 服务器端必须配置有效的 TLS 证书
> - 不支持 HTTP 和 SOCKS5 协议
> - 其他代理客户端无法连接本插件的服务器

### 导入规则

1. 切换到「规则」标签页
2. 点击「+ 添加规则源」
3. 输入规则文件 URL 或直接粘贴规则内容
4. 点击「导入」然后「保存」

## 🔒 技术原理：TLS 加密的 HTTPS 代理

### 工作流程

```
┌──────────┐      TLS 加密       ┌──────────┐      TLS 加密       ┌──────────┐
│ 浏览器   │ ──────────────────→ │ 代理服务器│ ──────────────────→ │ 目标网站 │
│ (插件)   │   CONNECT 隧道      │          │                     │          │
└──────────┘                     └──────────┘                     └──────────┘
```

### 安全特性

- 浏览器→代理：TLS 加密
- 代理→目标：TLS 加密
- 代理无法解密流量内容

## 🖥️ 服务器端要求

本插件需要服务器端运行支持 **TLS 加密 HTTPS 代理** 的软件。

### 推荐软件

| 软件 | TLS 加密 HTTPS 代理 | 说明 |
|------|-------------------|------|
| **Squid** | ✅ 原生支持 | 标准实现，推荐使用 |
| **3proxy** | ✅ 支持 | 轻量级，支持 HTTPS 代理 |
| **Xray** | ⚠️ 需配置 | HTTP 入站 + TLS，非标准实现 |

> **注意**：如需使用本插件，需在服务器上安装 **Squid** 或 **3proxy** 并配置 TLS 证书。

## 🏗️ 架构设计

### 模块划分

| 模块 | 文件 | 职责 |
|------|------|------|
| **配置管理** | `manifest.json` | 扩展元数据、权限声明 |
| **后台服务** | `background.js` | 代理控制、认证处理、规则管理 |
| **用户界面** | `popup.html/css/js` | 弹窗交互、配置编辑 |

### 数据流

```
用户操作 → popup.js → chrome.storage → background.js → chrome.proxy
                                    ↓
                              cachedConfig (内存缓存)
```

## 🔑 核心函数说明

### background.js

| 函数名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| `createDefaultConfig()` | 无 | Object | 创建默认配置对象 |
| `updateProxy(config)` | config | void | 更新代理设置 |
| `generatePacScript(config, server)` | config, server | string | 生成 PAC 脚本 |
| `getActiveServer(config)` | config | Object | 获取当前活动服务器 |
| `parseRules(text)` | text | Array | 解析规则文件 |
| `base64Decode(str)` | str | string/null | Base64 解码 |
| `testServerConnection(server)` | server | Promise | 测试服务器连接 |
| `checkForUpdates()` | 无 | Promise | 检查更新 |
| `forceReauth(config)` | config | void | 强制重新认证 |
| `updateBadge(enabled)` | enabled | void | 更新工具栏图标 |

### popup.js

| 函数名 | 参数 | 返回值 | 说明 |
|--------|------|--------|------|
| `loadConfig()` | 无 | void | 从 storage 加载配置 |
| `saveConfig()` | 无 | void | 保存配置到 storage |
| `updateUI()` | 无 | void | 更新界面显示 |
| `renderServerList()` | 无 | void | 渲染服务器列表 |
| `renderCurrentServer()` | 无 | void | 渲染当前服务器信息 |

| `fetchRules(url)` | url | Promise | 获取规则文件 |

| `showToast(message, type)` | message, type | void | 显示提示消息 |
| `showConfirm(message)` | message | Promise | 显示确认对话框 |

## 📝 配置数据结构

```javascript
{
  enabled: false,              // 是否启用代理
  servers: [                   // 服务器列表
    {
      id: 1,
      name: "Server Name",
      type: "https",           // 仅支持 https（TLS 加密）
      host: "proxy.example.com",
      port: 443,
      username: "user",
      password: "pass"
    }
  ],
  activeServerId: 1,           // 当前活动服务器 ID
  proxyMode: "rules",          // all | rules | bypass
  rules: [],                   // 自定义规则
  ruleSources: [               // 规则源列表
    {
      id: "gfwlist",
      name: "GFWList",
      ruleType: "proxy",       // proxy | direct
      enabled: true,
      url: "https://...",
      rules: ["||example.com"],
      lastUpdate: "2024-01-01T00:00:00.000Z"
    }
  ],
  lastUpdate: "2024-01-01T00:00:00.000Z"
}
```

## 📜 更新日志

### v1.2.2
- **代理状态检测重构**：使用真实流量监控替代主动测试，通过 webRequest 监听实际请求推断代理状态
- **移除 forceReauth 端口切换机制**：由于 HTTPS 代理不触发 onAuthRequired，该机制对 HTTPS 代理无效
- **服务器表单加回端口输入**：支持自定义端口（1-65535），默认 443
- **全局清理**：删除死代码约 100 行，合并重复函数
- **新增启用/禁用状态图标**：icon16-on/off.png 等

### v1.1.0
- **新增服务器连接状态显示**：在当前服务器条目显示认证状态（已连接/认证失败/连接失败/已断开）
- **优化测速功能**：点击当前服务器条目即可测速，测速结果与状态分离显示
- **改进弹窗交互**：添加/编辑服务器和规则源时自动撑开背景面板
- **修复认证信息变更问题**：凭据修改后自动切换端口绕过浏览器认证缓存
- **优化服务器测试**：使用 WebSocket 测试 TCP 连接延迟
- **代码重构**：移除心跳检测，改为单次检测模式

### v1.0.2

- 优化代码结构

### v1.0.1

- 修复凭据变更时的认证缓存问题
