# OT512 Proxy - 浏览器代理插件

一款简洁高效的浏览器代理插件，支持 HTTPS/TLS 加密连接，保护您的网络通信安全。

## 功能特性

### 🔐 安全连接
- **HTTPS/TLS 加密**：所有代理流量通过 TLS 加密传输，防止流量被监听和分析
- **用户认证**：支持用户名/密码认证，保护代理服务器安全

### 🌐 代理模式
- **全局模式**：所有网络流量通过代理服务器
- **智能模式**：根据规则自动分流，仅匹配的网站走代理
- **直连模式**：所有流量直接连接，不使用代理

### 📋 规则管理
- **规则源支持**：支持从 URL 导入规则列表
- **Base64 解码**：自动识别并解码 Base64 编码的规则
- **规则类型**：支持代理规则和直连规则
- **实时更新**：可随时更新规则源

### ⚡ 服务器管理
- **多服务器支持**：可添加多个代理服务器
- **一键切换**：快速切换当前使用的服务器
- **连接测试**：测试服务器可达性和延迟
- **协议支持**：HTTP、HTTPS、SOCKS5

### 🎨 用户体验
- **状态图标**：工具栏图标随代理状态变化
- **进度动画**：测试连接时显示进度条
- **Toast 提示**：操作结果即时反馈
- **深色主题**：现代化深色界面设计

## 安装方法

### Edge 浏览器
1. 下载扩展文件
2. 打开 `edge://extensions/`
3. 开启"开发人员模式"
4. 点击"加载解压缩的扩展"
5. 选择扩展目录

### Chrome 浏览器
1. 下载扩展文件
2. 打开 `chrome://extensions/`
3. 开启"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择扩展目录

## 使用说明

### 1. 添加服务器
1. 点击"服务器"标签
2. 点击"+ 添加服务器"
3. 填写服务器信息：
   - **服务器名称**：自定义名称
   - **协议**：选择 HTTPS（推荐）、HTTP 或 SOCKS5
   - **服务器地址**：域名或 IP 地址
   - **用户名/密码**：认证信息（如需要）
4. 点击"保存"

### 2. 导入规则
1. 点击"规则"标签
2. 点击"+ 添加规则源"
3. 填写规则源信息：
   - **规则源名称**：自定义名称
   - **规则类型**：执行代理或执行直连
   - **规则文件 URL**：规则列表地址
   - 或直接粘贴规则内容
4. 点击"导入"，然后"保存"

### 3. 选择模式
- **全局**：所有流量走代理
- **智能**：根据规则分流
- **直连**：不使用代理

### 4. 启用代理
点击顶部开关启用/禁用代理

## 规则格式支持

支持常见的规则格式：
- `||example.com` - 域名匹配
- `*.example.com` - 通配符匹配
- `example.com` - 直接域名
- Base64 编码的规则列表（如 GFWList）

## 技术特点

- **Manifest V3**：使用最新的扩展 manifest 版本
- **Service Worker**：后台服务使用 Service Worker
- **PAC 脚本**：智能模式使用 PAC 脚本实现规则分流
- **WebSocket 测试**：使用 WebSocket 测试服务器可达性

## 隐私声明

- 本扩展不收集任何用户数据
- 所有配置信息存储在本地
- 不与任何第三方服务器通信（除规则源 URL 外）
